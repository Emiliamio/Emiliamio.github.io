## 🎯 二、招投标技术专家质询核心攻防话术

在招投标评审现场，技术专家最常提出的挑战及标准技术应答如下：

### 1. 为什么坚决选用纯血 Java 21 而不是 Python 框架？
* **核心应答**：
  1. **生产机房门禁合规**：国内 80% 以上政企机房不允许安装 Conda 与动态包编译依赖，Java 拥有最成熟的微服务治理、日志审计与监控体系；
  2. **高并发与长连接吞吐**：在数千员工并发访问 SSE 流式长连接时，Java 21 虚拟线程将内存消耗降低 90% 以上；
  3. **数据隔离物理安全**：基于 JsqlParser 在 AST 抽象语法树层级做强拦截，杜绝应用层 SQL 拼接带来的越权泄露风险。

### 2. 混合检索召回率如何量化验证？
* **核心应答**：
  通过 **pgvector HNSW 稠密检索 + tsvector BM25 全文稀疏检索 + RRF 倒数排名融合 + Cross-Encoder 深度重排**，在专业合同编号、精确金额和缩写术语场景下，精准召回率较传统单一向量检索提升 **35% 以上**，内置 RAGAS 量化沙盒自动输出评测雷达图。
